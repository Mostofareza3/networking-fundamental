Preface

এই বইটি কীভাবে পড়বেন

Networking শেখার সবচেয়ে বড় সমস্যা হলো — বেশিরভাগ resource শুরু করে terminology দিয়ে। OSI-এর সাতটি layer মুখস্থ করানো হয়, subnet mask-এর table দেওয়া হয়, protocol-এর acronym-এর তালিকা ধরিয়ে দেওয়া হয়। তারপর reader আটকে যায়, কারণ সে জানে নাম, কিন্তু বোঝে না কেন।

এই বইয়ের approach উল্টো। প্রতিটি chapter শুরু হয় একটি problem দিয়ে — এমন একটি সমস্যা যেটি সমাধান করতে গিয়েই মানুষ এই technology-টি আবিষ্কার করেছিল। তারপর আসে সেই সমাধানের নাম, তারপর mechanism, তারপর command।

📐 Core Philosophy

Memorization নয়, Mental Model। আপনি যদি TCP-এর header-এর প্রতিটি field মুখস্থ করেন কিন্তু বুঝতে না পারেন কেন sequence number দরকার — আপনি কিছুই শেখেননি। আর আপনি যদি sequence number-এর প্রয়োজনীয়তা বোঝেন, header-এর details পাঁচ মিনিটে খুঁজে নেওয়া যায়।

আপনি কোথায় আছেন

এই বইটি একটি বড় systems learning journey-এর তৃতীয় ধাপ:

Linux Fundamentals
        ↓
    (process, file, permission, shell, kernel)
        ↓
Operating Systems Fundamentals
        ↓
    (process, memory, syscall, scheduling, I/O)
        ↓
Networking Fundamentals   ← আপনি এখানে
        ↓
    (packet, IP, TCP, DNS, HTTP, TLS)

আপনার কাছ থেকে যা ধরে নেওয়া হচ্ছে: আপনি programming জানেন, Linux terminal-এ কাজ করতে পারেন, process এবং system call কী তা জানেন। যা ধরে নেওয়া হচ্ছে না: আপনি networking-এর কিছুই জানেন। প্রতিটি networking concept শূন্য থেকে শুরু হবে।

প্রতিটি chapter-এর গঠন

সব chapter-এ সব section থাকবে না — যেটি প্রাসঙ্গিক, সেটিই থাকবে। কিন্তু সাধারণ progression এটি:

        ↓

        ↓

        ↓

        ↓

দুটি mental model যা পুরো বই জুড়ে ফিরে আসবে

যদি এই বই থেকে আপনি মাত্র দুটি জিনিস মনে রাখেন, সেগুলো এই দুটি হোক। এগুলো প্রথমবার অর্ধেক বুঝলেও সমস্যা নেই — প্রতিটি chapter এদের একটু একটু করে পরিষ্কার করবে।

MODEL 1 — Vertical Stack (একটি machine-এর ভেতরে)

    Process          ← আপনার application code
       ↓
    Socket           ← OS-এর দেওয়া network handle
       ↓
    System Call      ← user space থেকে kernel space
       ↓
    Kernel           ← TCP/IP stack এখানে থাকে
       ↓
    TCP/IP Stack     ← segment → packet → frame
       ↓
    NIC              ← hardware, bits পাঠায়
       ↓
    Ethernet / Wi-Fi ← physical medium
       ↓
    Switch → Router → Internet → Server


MODEL 2 — Protocol Layering (একটি byte-এর মোড়ক)

    HTTP             ← "GET /users দাও"
       ↓
    TLS              ← "কিন্তু encrypted করে"
       ↓
    TCP / QUIC       ← "reliable, ordered ভাবে"
       ↓
    IP               ← "এই address-এ পাঠাও"
       ↓
    Ethernet / Wi-Fi ← "পরের hop-এ পৌঁছে দাও"
       ↓
    Physical medium  ← "0 আর 1 হিসেবে"
🧠 Mental Model

Model 1 বলে data কোন কোন component-এর মধ্য দিয়ে যায়। Model 2 বলে data-এর গায়ে কোন কোন header জড়ানো হয়। দুটো একই ঘটনার দুই দৃষ্টিকোণ। বইয়ের শেষে (Chapter 48) আমরা এই দুটোকে এক করে একটি single end-to-end journey দেখব।

Labs সম্পর্কে

প্রতিটি major section-এর শেষে ছোট experiment আছে। এগুলো Linux/macOS terminal-এ চলবে। প্রতিটি lab-এর আগে বলা হবে আমরা কী observe করার চেষ্টা করছি, আর শেষে আমরা কী শিখলাম। Lab গুলো skip করলেও বই বোঝা যাবে — কিন্তু নিজের machine-এ packet দেখলে concept-টা যেভাবে স্থায়ী হয়, পড়ে সেভাবে হয় না।

ℹ️ macOS ব্যবহারকারীদের জন্য

বইয়ে মূলত Linux command ব্যবহার করা হয়েছে (ip, ss)। macOS-এ সমতুল্য command হলো ifconfig/netstat -rn এবং netstat -an/lsof -i। যেখানে পার্থক্য গুরুত্বপূর্ণ, সেখানে উল্লেখ করা আছে।
